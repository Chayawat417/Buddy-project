# Buddy — คู่มือใช้งานแบบเข้าใจง่าย

Buddy ช่วยแบ่งรายได้ของคุณออกเป็นงบประมาณรายเดือน เช่น ค่าอาหาร ค่าเดินทาง และค่าเช่าบ้าน ใช้ได้ทั้งบนมือถือและคอมพิวเตอร์ผ่าน Chrome

## เริ่มใช้ Buddy บน Windows

อย่าเปิดไฟล์ `index.html` ด้วยการดับเบิลคลิก เพราะไฟล์นี้เป็นส่วนประกอบของแอป ไม่ใช่ตัวเปิดแอปโดยตรง การเปิดแบบนั้นอาจเห็นหน้าว่าง

1. ติดตั้ง Node.js เวอร์ชัน `22.12` ขึ้นไป หากยังไม่มี (ดาวน์โหลดจากเว็บไซต์ Node.js อย่างเป็นทางการ)
2. เปิดโฟลเดอร์ Buddy แล้วดับเบิลคลิกไฟล์ `start-buddy.bat`
3. ครั้งแรก โปรแกรมจะเตรียมไฟล์ที่จำเป็นให้อัตโนมัติ รอจน Chrome เปิดหน้า Buddy
4. ใช้งาน Buddy ตามปกติ และอย่าปิดหน้าต่างสีดำที่เปิดขึ้นมาในระหว่างใช้งาน
5. เมื่อใช้งานเสร็จ ปิดหน้าต่างสีดำเพื่อหยุด Buddy

ถ้า Chrome ไม่เปิดเอง ให้รอข้อความ `Local` ในหน้าต่างสีดำ แล้วคัดลอกที่อยู่เว็บที่แสดง (ปกติคือ `http://127.0.0.1:5173/`) ไปเปิดใน Chrome

หากต้องการเปิดใช้งานแอป ให้เริ่มสร้างโปรไฟล์ได้เลย:

1. กด **เพิ่มโปรไฟล์** แล้วตั้งชื่อให้ตัวเองหรือสมาชิกในครอบครัว
2. เลือกเดือนที่ต้องการวางแผน
3. ใส่รายได้สุทธิของเดือนนั้น แล้วกด **บันทึกรายได้**
4. ไปที่หน้า **ตั้งค่าหมวด** เพื่อเพิ่มชื่อหมวดที่ต้องการใช้ แล้วกลับมาที่หน้างบประมาณ
5. เลือกชื่อหมวดจาก dropdown ใส่จำนวนเงิน แล้วกด **เพิ่มรายการงบประมาณ**
6. หากต้องการใช้หมวดเดิมจากเดือนที่แล้ว กด **คัดลอกหมวดจากเดือนก่อน** ระบบจะเพิ่มเฉพาะหมวดที่ยังไม่มี และไม่เปลี่ยนรายได้หรือหมวดที่มีอยู่แล้ว
7. ดูช่องสรุปยอดเพื่อเช็กว่าแบ่งเงินครบพอดี ยังเหลือ หรือแบ่งเกินรายได้

เมื่อกด **เพิ่มรายการงบประมาณ** ระบบจะบันทึกรายการลงในเบราว์เซอร์ทันที หากแก้จำนวนเงินหรือเปลี่ยนหมวดในตาราง ปุ่ม **บันทึก** จะแสดงเฉพาะแถวที่มีการแก้ไขที่ยังไม่บันทึก กดปุ่มนั้นเพื่อยืนยันการแก้ไข หากยอดเงินผิดรูปแบบหรือมีหมวดซ้ำ ระบบจะแสดงข้อความแจ้งข้อผิดพลาดและไม่บันทึก เมื่อบันทึกสำเร็จจะแสดง **บันทึกแล้ว**

กด **เปรียบเทียบกับเดือนก่อน** เพื่อเปิดตารางเทียบรายได้ ยอดจัดสรร ยอดคงเหลือ และแต่ละหมวดของเดือนที่เลือกกับเดือนก่อนหน้า ตารางนี้ใช้เฉพาะข้อมูลที่บันทึกแล้ว ค่าบวก/ลบแสดงว่าเดือนนี้มากกว่าหรือน้อยกว่าเดือนก่อน และรายได้ที่ยังไม่บันทึกจะแสดงแยกจาก 0 บาท กดปุ่มเดิมอีกครั้งเพื่อซ่อนตาราง

## ตั้งค่าหมวดงบประมาณ

หน้า **ตั้งค่าหมวด** เป็นหน้าสำหรับจัดการรายการชื่อหมวดที่ใช้ร่วมกันทุกโปรไฟล์:

- เพิ่มหมวดใหม่จากหน้านี้ แล้วชื่อหมวดจะเป็นตัวเลือกใน dropdown ของหน้างบประมาณ
- เปลี่ยนชื่อหมวดได้ โดยเลือกได้ว่าจะเปลี่ยนชื่อในข้อมูลเดือนเก่าทุกโปรไฟล์ด้วยหรือเก็บชื่อเก่าไว้
- ซ่อนหมวดเพื่อเอาออกจากตัวเลือกใหม่ได้ โดยข้อมูลและยอดที่บันทึกไปแล้วจะไม่ถูกลบ หมวดที่ซ่อนสามารถนำกลับมาแสดงได้
- หมวดที่มีอยู่ในข้อมูลเดิมจะถูกนำมาเป็นตัวเลือกเมื่ออัปเกรด Buddy

ปุ่มด้านบนใช้สลับระหว่าง **โหมดมืด** และ **โหมดสว่าง** โดย Buddy จะจำตัวเลือกไว้ใน Chrome ของอุปกรณ์นี้

## โปรไฟล์และข้อมูลของคุณ

- แต่ละคนใช้โปรไฟล์แยกกันได้ ชื่อโปรไฟล์ต้องไม่ซ้ำและยาวไม่เกิน 40 ตัวอักษร
- ข้อมูลเก็บอยู่ใน Chrome บนอุปกรณ์นี้ ไม่ได้ส่งไปเก็บบนอินเทอร์เน็ต
- ผู้ใช้บัญชี Chrome/อุปกรณ์เดียวกันอาจเปิดดูโปรไฟล์อื่นได้ เพราะไม่มีรหัสผ่านหรือล็อกโปรไฟล์
- หากลบโปรไฟล์ แผนรายได้และงบประมาณของโปรไฟล์นั้นจะถูกลบด้วย และกู้คืนไม่ได้ เว้นแต่มีไฟล์สำรอง

## ใช้งานโดยไม่ต่ออินเทอร์เน็ต

การเปิด Buddy ด้วย `start-buddy.bat` จะเปิดเว็บเซิร์ฟเวอร์ไว้ในเครื่องของคุณ ไม่ต้องต่ออินเทอร์เน็ตเพื่อใช้แอปหลังจากเตรียมไฟล์ครั้งแรกเสร็จ แต่ต้องเปิดหน้าต่างสีดำค้างไว้ตลอดเวลาที่ใช้งาน หากเป็นการเปิดครั้งแรก ต้องต่ออินเทอร์เน็ตเพื่อดาวน์โหลดไฟล์ที่จำเป็น

การติดตั้ง Buddy เป็นแอปแยกจากการเปิดด้วยไฟล์ `.bat` และต้องนำแอปขึ้นให้บริการผ่าน HTTPS ก่อน (เช่น เว็บไซต์ส่วนตัวที่มี HTTPS) เมื่อเปิดเว็บไซต์นั้นใน Chrome แล้ว Chrome อาจแสดงตัวเลือก **ติดตั้ง Buddy** การเปิดด้วยไฟล์ `.bat` เหมาะสำหรับใช้บนเครื่องนี้ แต่จะไม่แสดงปุ่มติดตั้งแอป

การติดตั้งหรือใช้งานออฟไลน์ไม่ได้ทำให้ข้อมูลสำรองโดยอัตโนมัติ หากล้างข้อมูล Chrome เปลี่ยนอุปกรณ์ หรือเกิดปัญหากับอุปกรณ์ ข้อมูลอาจหายได้ ควรส่งออกไฟล์สำรองเก็บไว้เป็นระยะ

เมื่อใช้งาน Buddy ในรูปแบบเว็บไซต์ที่ติดตั้งได้ และมีเวอร์ชันใหม่ ให้บันทึกสิ่งที่กำลังแก้ก่อน แล้วจึงกด **อัปเดตแอป**

## สำรองและกู้คืนข้อมูล

1. กด **ส่งออกไฟล์สำรอง** เพื่อดาวน์โหลดไฟล์ `.json`
2. เก็บไฟล์ไว้ในที่ปลอดภัย ไฟล์นี้รวมข้อมูลของทุกโปรไฟล์และอ่านได้โดยไม่ต้องมีรหัสผ่าน
3. หากต้องการกู้คืน กด **นำเข้าไฟล์สำรอง** แล้วเลือกไฟล์ที่เคยส่งออก
4. การนำเข้าจะแทนที่ข้อมูลทั้งหมดที่อยู่ใน Buddy เครื่องนี้ ควรส่งออกข้อมูลปัจจุบันไว้ก่อน

Buddy ปฏิเสธไฟล์ที่ไม่ถูกต้องหรือมีขนาดเกิน 10 MB โดยไม่แทนที่ข้อมูลเดิม

## ดูรายงานและบันทึกเป็น PDF

ในส่วน **รายงานงบประมาณ** เลือกได้ว่าจะดูรายไตรมาสหรือรายปี รายงานแสดงรายได้ ยอดจัดสรร ยอดคงเหลือ และยอดรวมแยกตามหมวดของโปรไฟล์ที่เลือก

เดือนที่ยังไม่ได้กรอกรายได้จะแสดงว่า **ยังไม่บันทึก** ไม่ใช่รายได้ 0 บาท เมื่อพร้อมบันทึกรายงาน ให้กด **พิมพ์ / บันทึก PDF** แล้วเลือก **Save as PDF** ในหน้าต่างพิมพ์ของ Chrome

## หากต้องการเปิดหรือแก้ไขโปรเจกต์ (สำหรับผู้พัฒนา)

ต้องติดตั้ง Node.js เวอร์ชัน `22.12` ขึ้นไป หรือ `24` ขึ้นไป และติดตั้ง npm ซึ่งมากับ Node.js

เปิดเทอร์มินัลในโฟลเดอร์โปรเจกต์ แล้วรัน:

```sh
npm install
npm run dev
```

เปิดที่อยู่เว็บไซต์ที่แสดงในเทอร์มินัลด้วย Chrome

คำสั่งที่ใช้บ่อย:

| คำสั่ง | ใช้ทำอะไร |
| --- | --- |
| `npm run dev` | เปิดแอปสำหรับพัฒนา |
| `npm test` | ตรวจว่าการคำนวณและการจัดเก็บข้อมูลทำงานตามที่คาด |
| `npm run build` | ตรวจโค้ดและเตรียมไฟล์แอปสำหรับนำไปเผยแพร่ไว้ใน `dist/` |
| `npm run preview` | เปิดดูไฟล์ที่เตรียมไว้ก่อนนำไปเผยแพร่ |

การตรวจใช้งานออฟไลน์ต้องใช้ไฟล์ที่ build แล้ว: รัน `npm run build` แล้ว `npm run preview`, เปิดแอปออนไลน์หนึ่งครั้ง, รอข้อความ **Buddy พร้อมใช้งานออฟไลน์แล้ว** จากนั้นตั้ง Chrome DevTools เป็น Offline แล้วรีโหลดหน้า

## เผยแพร่ทดสอบบน GitHub Pages

โปรเจกต์มี workflow `.github/workflows/deploy-pages.yml` ที่ build และเผยแพร่แอปอัตโนมัติทุกครั้งที่ push เข้า branch `main`

1. สร้าง repository ใหม่บน GitHub แล้ว push โค้ดนี้ขึ้นไปที่ branch `main` (ห้ามรวม `node_modules/` และ `dist/`)
2. ใน repository ไปที่ **Settings → Pages** ตรง **Source** เลือก **GitHub Actions**
3. ไปที่แท็บ **Actions** รอให้ “Deploy to GitHub Pages” ขึ้นเครื่องหมายถูก (ถ้ารันก่อนตั้งค่าข้อ 2 แล้วล้ม ให้กด **Re-run all jobs**)
4. เปิดแอปที่ `https://ชื่อผู้ใช้.github.io/ชื่อrepository/` ด้วย Chrome แล้วกดติดตั้งได้

ข้อควรรู้:

- ข้อมูลงบประมาณยังเก็บในเบราว์เซอร์ของแต่ละเครื่อง ไม่ได้ส่งขึ้น GitHub แต่ไม่ย้ายข้ามที่อยู่เว็บ ถ้าต้องการใช้ข้อมูลจากเครื่องเดิม ให้สำรองข้อมูลจากแอปเดิมแล้วนำเข้าในแอปบน GitHub Pages
- Repository แบบ public ทำให้ทุกคนเห็นโค้ด (ไม่ใช่ข้อมูลงบประมาณ) ส่วน GitHub Pages จาก repository แบบ private ต้องใช้บัญชี GitHub แบบเสียเงิน
- แอปใช้ Vite `base` ตามชื่อ repository ที่ workflow ส่งให้ตอน build จึงไม่ต้องแก้โค้ดเมื่อเปลี่ยนชื่อ repository

## ไฟล์โปรเจกต์อยู่ตรงไหน

```text
src/
  features/       หน้าจอและการทำงาน เช่น โปรไฟล์ หมวด งบประมาณ รายงาน และสำรองข้อมูล
  data/           การอ่านและบันทึกข้อมูลในเบราว์เซอร์
  domain/         กฎคำนวณเงินและรายงาน
  styles/         สี ระยะห่าง และรูปแบบหน้าจอ
  App.tsx         รวมส่วนต่าง ๆ ของแอปเข้าด้วยกัน
  main.tsx        จุดเริ่มต้นของแอป
public/           ไฟล์ที่ต้องเผยแพร่ตรง ๆ เช่น ไอคอนแอป
```

## ข้อมูลสำหรับผู้ดูแลโปรเจกต์

- ใช้ React สร้างหน้าจอ, TypeScript ช่วยตรวจความถูกต้องของโค้ด และ Vite ช่วยเปิด/สร้างแอป
- ใช้ IndexedDB ซึ่งเป็นที่เก็บข้อมูลใน Chrome เพื่อให้ข้อมูลอยู่บนอุปกรณ์และใช้งานออฟไลน์ได้
- ใช้หน่วยสตางค์เป็นจำนวนเต็มในการคำนวณ เพื่อลดความคลาดเคลื่อนของตัวเลขเงิน
- ใช้ `vite-plugin-pwa` สร้างไฟล์สำหรับติดตั้งและใช้งานออฟไลน์
- ไม่มีเซิร์ฟเวอร์ บัญชีผู้ใช้ รหัสผ่าน การเข้ารหัส หรือการเชื่อมข้อมูลระหว่างอุปกรณ์
- ไม่ต้องตั้งค่า secret หรือ environment variable สำหรับการใช้งานปัจจุบัน ดู `.env.example` ได้
- เวอร์ชันของเครื่องมือและแพ็กเกจถูกกำหนดไว้ใน `package.json` และ `package-lock.json`

### อัปเดตแพ็กเกจ

ตรวจว่ามีแพ็กเกจใดออกรุ่นใหม่ด้วย:

```sh
npm outdated
```

จากนั้นอัปเดตเฉพาะแพ็กเกจที่ต้องการ โดยใส่รุ่นที่ต้องการใช้แทน `<version>`:

```sh
npm install --save-exact <package>@<version>
```

ถ้าเป็นเครื่องมือสำหรับพัฒนาเท่านั้น ให้ใช้:

```sh
npm install --save-dev --save-exact <package>@<version>
```

หลังอัปเดต ให้รัน `npm run build` และ `npm test` ก่อนนำไปใช้งาน

รายละเอียด Flow ที่ยืนยันไว้ การตัดสินใจ และผลการทำงานแต่ละขั้น อยู่ใน `PROGRESS.md`
